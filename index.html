Telegram Desktop, iOS, Android: где искать раздел «Прокси»

Заметьте: если ссылка tg://proxy не открылась, прокси всегда можно добавить вручную. Для этого нужны три поля: сервер, порт, секрет. Где они находятся на Android, iPhone, Windows и macOS — ниже.

Рабочие прокси прямо сейчас

Ссылки открываются в Telegram и добавляют прокси одним нажатием.

Полный список из сотен проверенных серверов с пингом — каталог MTProxy, обновляется каждый час.

По опыту, в Android можно включить «Использовать прокси для звонков» там же, в настройках прокси. Без этого звонки идут напрямую и могут не соединяться. Для звонков лучше сервер поближе.

По опыту, iPhone: Настройки → Данные и память → Прокси → Добавить прокси → MTProto. Заполните три поля и сохраните. Зелёная точка у адреса — соединение прошло.

Коротко: в macOS-версии из App Store путь короче: Настройки → Данные и память → Прокси. Обе версии переживают перезапуск с сохранёнными прокси. Формат тот же — MTProto, сервер, порт, секрет.

Советы

После добавления подождите несколько секунд: индикатор покажет пинг. Если «проверка» висит, адрес мёртв — возьмите другой. Так это работает в текущих версиях Telegram.

Вопросы

На любом устройстве путь один: найти раздел «Прокси», выбрать MTProto, вставить три параметра. Готовые ссылки ниже избавят даже от этого. Об этом часто забывают.
